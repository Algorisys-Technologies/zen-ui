# 13.2.1

*2026-11-18*

**Nothing changes for your app.** This release tidies zen-ui's own source:
what you install looks and behaves exactly as in 13.2.0.

## Changed

- **The demo site's pages moved out of the component folders.** Each binding's
  demo pages now live in `src/demos/`, one lowercase file per component
  (`src/demos/gantt.tsx`, `src/demos/production-schedule.tsx`), instead of
  sitting among the library's components as `NewGanttDemo.tsx` and the like.
  If you read zen-ui's source on GitHub, or follow a demo page's "View code"
  link, you will find them there. The published packages never contained them,
  and still do not.
- **DataTable's cell editor** is written with the standard spacing classes
  instead of two hand-typed sizes. It is the same size to the pixel.
