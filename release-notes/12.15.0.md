# 12.15.0

*2026-11-17*

**Colour a schedule by your own data — now in every binding.**
12.14.0 shipped this in Solid first. React, vanilla and web components now
have it too, with the same props: Gantt and ProductionSchedule can show which
shift an operation runs on, and tell a job's next step apart from a wait on
another job, without giving up the on-time / delayed colours.

Nothing breaks. Every option is off until you set it, and a chart that sets
none draws exactly as before. Nothing changes in Solid since 12.14.0.

## New (React, vanilla, web components)

- **A stripe on the bar for your own category.** `barAccent` returns a CSS
  colour for a narrow stripe on the bar's leading edge, so an operation can
  say "second shift" while its fill still says "delayed". `barClassName`
  could not do this: it replaces the status colour.

  ```tsx
  // shiftColour can come straight from your database — any CSS colour works.
  const shiftColour = { GS: "var(--zen-color-accent-orange)", S2: "#7c3aed" };

  <Gantt tasks={operations} barAccent={(task) => shiftColour[shiftOf[task.id]]} />
  ```

  It is a colour rather than a class on purpose. A stylesheet is built before
  your app runs, so it cannot contain a class for a colour that only exists
  in your records.

- **Arrows that say what kind of link they are.** A dependency can carry a
  `kind` of your own naming, such as `"sequence"` for the next step of the
  same order or `"dependency"` for a wait on a different one. `dependencyStyle`
  turns each kind into a colour and a dash:

  ```tsx
  const linkStyle = {
    sequence: { color: "var(--zen-color-info)" },
    dependency: { color: "var(--zen-color-accent-magenta)", dash: "4 3" },
  };

  <ProductionSchedule
    resources={cells}
    operations={jobs}
    dependencies={[
      { from: "op10", to: "op20", kind: "sequence" },
      { from: "op20", to: "op35", kind: "dependency" },
    ]}
    dependencyStyle={(link) => linkStyle[link.kind]}
  />
  ```

  Give each kind a dash as well as a colour, because red already means late
  on these charts. A link the plan breaks is still drawn red and thick, and
  keeps its dash. Draw a legend beside the chart: only you know what your
  kinds are called. The demo pages show one.

- **Vanilla:** the same options on the factories,
  `Gantt({ barAccent, dependencyStyle })`.
- **Web components:** both are functions, so set them as **properties**,
  like `rowClassName`:

  ```js
  const chart = document.querySelector("zen-gantt");
  chart.barAccent = (task) => shiftColour[shiftOf[task.id]];
  chart.dependencyStyle = (link) => linkStyle[link.kind];
  ```

- **A shift band behind the row** already worked through `rowClassName`.
  It now shows on weekends and on today's column too (see Fixed).

## Fixed (React, vanilla, web components)

- **A row tint disappeared on weekends and on today's column** in Gantt and
  ProductionSchedule. Those columns' shading was meant to be see-through but
  was drawn solid, so a `rowClassName` band stopped at every weekend. On a
  tinted row the shading now lets the tint through. Rows without a tint look
  exactly as they did.
