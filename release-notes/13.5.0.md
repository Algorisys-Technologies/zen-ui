# 13.5.0

*2026-11-20*

**The schedules scroll sideways more cleanly.** Two things about the frozen
task columns on `Gantt` and `ProductionSchedule`: the horizontal scrollbar no
longer runs underneath them, and dependency lines no longer show through them.

Nothing to change in your code, and nothing moves: the chart is the same size
and the scrollbar is in the same place. It is just shorter.

## Improved

- **The horizontal scrollbar stays under the timeline.** It used to span the
  whole chart, including the task columns that do not scroll, so its left end
  sat under "Task" and "Status" and the thumb travelled a track longer than
  the thing it moved. It now starts where the frozen columns end. Under a
  right-to-left layout it is mirrored with the rest of the chart.

  This applies wherever scrollbars take up room, which is most desktop
  browsers on Windows and Linux. Where they float over the content and fade
  out (macOS by default, phones and tablets) the browser's own bar is left as
  it is.

  If you style scrollbars with a selector that targets the chart's scroller,
  the new bar is a separate element, marked `data-schedule-scrollbar`. A
  global rule such as `*::-webkit-scrollbar` already reaches it.

## Fixed

- **Dependency lines crossed the frozen columns.** With a `continuous` Gantt
  scrolled sideways, an arrow that ran along the line between two rows was
  drawn straight across the task columns, and the today marker left a dot on
  every row line. Both now pass under the columns, as the bars always did.
