# 12.8.1

*2026-11-06*

**An async Combobox in Solid now opens when its results arrive.** With
`onSearch`, typing into a Combobox whose list was empty ran the search and got
answers back, but the list stayed shut until you pressed the arrow. Type
"Indi" into a country field: India came back, nothing showed.

Nothing is removed or renamed, and nothing changes for a Combobox with
`options`.

## Fixed

- **Solid: the async list opens as you type.** It opens on the first
  keystroke with "Searching…", and the results appear in it as soon as the
  server answers. You no longer have to press the arrow.

- **Solid: results the server found are shown even when their label does not
  contain what you typed.** If your `onSearch` matches on a code, a keyword or
  a fuzzy match (typing "US" to find United States by its country code), the Combobox
  used to filter those results again by label and hide them. It now shows
  exactly what `onSearch` returned, the same as React and vanilla always did.

- **Solid: a search that fails no longer leaves the previous results up.** If
  `onSearch` rejects, the list empties and says "No results", as in the other
  bindings.

## Changed

Async Combobox and MultiCombobox now behave the same in React, Solid, vanilla
and `<zen-combobox>` / `<zen-multi-combobox>`. These are small changes to what
the list shows while a search is in flight:

- **"Searching…" shows from the keystroke**, not a quarter of a second later
  when the search actually starts. Until now React and vanilla briefly showed
  "No results" before every search, even ones that would find plenty.
- **The previous results are narrowed while you wait.** Type "Vu" over a list
  of frameworks and, until the server answers, you see Vue rather than every
  framework from the last search. When the answer arrives, it is shown as
  returned.
- **Solid's loading row says "Searching…"**, like the other bindings, instead
  of "Loading…". If a test of yours waits for the text "Loading…" inside a
  Solid Combobox, wait for "Searching…" instead. If you translate the message
  catalogue, the key is `combobox.searching`.
