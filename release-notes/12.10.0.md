# 12.10.0

*2026-11-16*

**A status bar, in Solid first.** `StatusBar` is the strip along the bottom of
an app, an editor or a panel: the state of what you are working on, and
shortcuts to the places it points at. It ships in `@algorisys/zen-ui-solid`
in this release; React, vanilla and web components follow in the next one,
with the same props.

Nothing breaks. This release adds one component and changes nothing that
exists.

## New

- **`StatusBar`** takes its items as data — a branch name, a problem count, a
  cursor position, a clock — and lays them out on two sides:

  ```tsx
  <StatusBar items={[
    { id: "branch", icon: "flag", label: "main", title: "Current branch" },
    { id: "problems", icon: "error", label: "2", title: "Problems", color: "error", onSelect: openProblems },
    { id: "cursor", label: "Ln 42, Col 7", align: "end", onSelect: goToLine },
    { id: "bell", icon: "bell", title: "Notifications", align: "end", onSelect: openInbox },
  ]} />
  ```

  - **What you can set.** An item with `onSelect` is a button; one without is
    plain text. `align: "end"` puts an item on the far side. `color` (info,
    success, warning, error) draws it as a soft chip, which stays readable on
    every bar style. `separatorBefore` draws a divider. The bar has three
    styles (`variant`: default, muted, or accent, which is filled with the
    primary colour) and two heights (`size`: sm, md). A `label` can be any
    element, including a `LiveIndicator`.
  - **When the bar is too narrow, the least important items give way first.**
    Each item can set a `priority`. When everything no longer fits, the lowest
    priority goes first, and between equals the item later in the list goes
    first. The items that remain keep their full width; they are never
    squashed, wrapped or cut off mid-word. Widen the bar and they come back.
    `onCollapse` tells you which items are hidden.
  - **Screen readers.** The bar is a named group ("Status bar", which you can
    translate or override with `label`). An item's `title` is its tooltip
    and also part of its name, so a button showing "2" is read as
    "Problems 2". Item text is **not** read out when it changes, or a clock
    would speak every second. Set `announce` on the one item a person needs
    to hear change ("Saving…" → "All changes saved"). A hidden item is gone
    for a screen reader too, so give anything nobody may miss a high
    priority.
  - **Rebuilding `items` on every update is fine.** The bar keeps its
    elements in place, so an `announce` item is still read out when its text
    changes.
