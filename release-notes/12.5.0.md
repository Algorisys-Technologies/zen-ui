# 12.5.0

*2026-11-05*

**DataTable columns you can manage from the keyboard, and Solid menus that no
longer freeze when you do.** Resize and reorder columns without a mouse, put
them back the way they were with one click, and give a column a proper name
when its header is a component.

Nothing is removed or renamed. The one change you might notice in an existing
table is a new "Reset columns" item at the bottom of its Columns menu.

## Fixed: Solid menus froze the page when opened from the keyboard

In the Solid binding, pressing Enter, Space or the down arrow on a dropdown
menu's button hung the browser tab for good. That covered every
`DropdownMenu`, and DataTable's Columns, Export and Group-by menus. A mouse
click worked, which is why it went unnoticed.

The cause was in Kobalte, the library Solid's menus are built on. zen-ui
carries a fix for it and ships it in the Solid package, so upgrading is all
you need to do. Select was not affected.

## DataTable

These are in React and Solid, where DataTable has a Columns menu and column
resizing.

- **Name a column whose header is a component.** If your `header` is a
  function, to right-align a figure column or add an icon, give the column
  `meta.label`. It is what the Columns menu shows, what a screen reader says
  for the sort button and the resize handle, and the column's heading in a
  CSV or server export. Without it, all of those showed the column's id
  ("posting_date").

  ```tsx
  {
    accessorKey: "grand_total",
    header: () => <span className="zen-block zen-text-end">Grand total</span>,
    meta: { label: "Grand total" },
  }
  ```

- **Reset columns.** Once someone has hidden, dragged and resized columns,
  and a `persistKey` remembers all of it, "Reset columns" at the bottom of the
  Columns menu puts order, widths, visibility and pinning back to how the
  table was set up, and saves that.

- **Resize a column from the keyboard.** Tab to a header's right edge and
  use the arrow keys: 16px a press, 64px with Shift. Screen readers hear the
  column's name and its width.

- **Move a column from the keyboard.** With `enableColumnOrdering`, open
  Columns, arrow to a column and press Alt+↑ or Alt+↓. The menu now lists
  columns in the order the table shows them, so you can see where each one
  went.

- **Clicking a sortable header still sorts** with column ordering on, and
  clicking a resize handle never does.
