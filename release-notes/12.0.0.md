# 12.0.0

One change: the `paper` theme's elevation steps are now tellable apart.

Major because it alters visual output — but **only if you use
`data-theme="paper"`**. If you do not, nothing in this release touches you and
the upgrade is a version number.

## Paper's elevation scale was too tight to read

Every step of the shadow scale sat within a few pixels of the next, so a
`raised` card and a `lifted` one looked like the same surface. Measured as the
peak pixel shift each shadow makes against the paper theme's own ground
(`#F0EBE0`):

| step | before | after |
|---|---|---|
| `xs` | 11 / 255 | **6** |
| `sm` (`raised`) | 13 | **12** |
| `md` | 15 | **19** |
| `lg` (`lifted`) | 20 | **30** |
| `xl` | 24 | **44** |
| `2xl` | 33 | **61** |

Six steps used to live inside a range of 22. `raised` to `lifted` was 7 apart;
it is now 18.

**`xs` gets fainter, not darker** — 11 down to 6. That is what spreading a scale
means rather than simply darkening it: the bottom has to drop for the top to
have room, or every step just moves up together and stays equally crowded.

Nothing else changed. The geometry — offsets, blurs, the negative spread from
`lg` up that keeps the shadow under the sheet rather than around it — is the
same as 11.0.0. A heavier shadow here reads as a sheet lifted further off the
desk, which is what the alpha is for.

### If you were relying on the old weights

They are tokens, so they are yours to set:

```css
[data-theme="paper"] {
  --zen-shadow-sm: 0 2px 4px 0 rgba(64, 54, 38, 0.07);
  --zen-shadow-lg: 0 6px 14px -2px rgba(64, 54, 38, 0.11);
}
```

## Still unchanged, and still known

The **shared** scale has the same complaint. In the default theme `raised` and
`lifted` measure 23 and 27 — only 4 apart — and in dark, 22 and 27. Widening
that would restyle every elevated component in every theme, for every consumer,
where this release reaches only what opts into `data-theme="paper"`. It stays a
separate decision.
