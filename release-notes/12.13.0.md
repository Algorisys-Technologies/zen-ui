# 12.13.0

*2026-11-17*

**Density, header styling and a pivot you can unfreeze, in every binding.**
This release lets you make the schedules, the planning calendar, the
spreadsheet grid and the tree compact or touch-sized, style the headers of the
schedules and the pivot, and turn off a pivot's frozen headers. It also brings
column pinning to vanilla's older virtualized table, which had it everywhere
else.

Nothing breaks. Every option is off until you set it, and a component that
sets none draws exactly as before.

## New

- **Density for the schedules, calendar, sheet and tree.** `density`
  takes `"compact"`, `"comfortable"` or `"touch"` on Gantt,
  ProductionSchedule, PlanningCalendar, SpreadsheetGrid and Tree.
  - **Comfortable** is the default, and is exactly the size each component
    always was.
  - **Touch** makes rows, appointments, cells and tree rows 48px tall, the
    same size as touch-density controls, for tablets on a shop floor. A
    Gantt or production bar becomes 32px, big enough to tap.
  - **Compact** fits more on screen: 28px schedule rows, 24px calendar lanes,
    20px cells.

  ```tsx
  <Gantt tasks={plan} density="touch" />
  <PlanningCalendar rows={team} density="compact" />
  ```

  It is a prop on purpose, not something these components pick up from
  `data-density`. These components have never followed that attribute, and
  starting to would resize the charts in every app that already sets it for
  its controls. An explicit `rowHeight` or `laneHeight` still wins over
  `density`. In web components it is a `density` attribute.
- **Style a schedule's header.** `headerClassName` on Gantt and
  ProductionSchedule styles the header row and its frozen left-hand pane. It
  is applied after their own classes, so your background and text colour win.
- **Style a pivot's headers.** `headerClassName` styles every column header,
  including the corner and the totals header. `rowHeaderClassName` styles
  every row label.
- **Turn a pivot's freeze off.** A pivot's headers stay in view while it
  scrolls, as before. `stickyHeader={false}` and `stickyRowHeaders={false}`
  let them scroll away with the cells, for a short grid that is read whole or
  printed. In web components these are `sticky-header="false"` and
  `sticky-row-headers="false"`; leaving them out keeps the headers frozen.

## Fixed

- **Vanilla and web components: pinned columns did nothing in the older
  virtualized table** (`enableVirtualization`). They now stay at the start or
  end edge, in right-to-left pages too, as they do in React and Solid. The
  checkbox column pins with them.
- **Vanilla and web components: a wide virtualized table's header did not
  scroll sideways with its rows**, so the column names drifted away from
  their columns. The header now follows.
- **Vanilla and web components: a footer without totals sat one column out
  of place** when the table had row selection. Every footer cell was one
  column to the left of its column.
