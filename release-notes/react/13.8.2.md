# zen-ui-react 13.8.2

*2026-11-27*

**KaTeX 0.18.2 and later can be installed beside zen-ui, and the npm page links
to the live demo.** Both reached Solid first (13.8.2 and 13.8.3); this release
brings them to React.

Nothing breaks. No prop, default or visual output changed.

## Fixed

- **The `katex` peer range is now `>=0.16.0 <0.20.0`.** The RichText editor's
  maths rendering declared `^0.16.0`, which kept apps on the 0.16 line. KaTeX
  before 0.18.2 has a prototype-pollution flaw that can bypass its `trust`
  restrictions (GitHub advisory, low severity), and the fix is only in 0.18.2
  onwards. Move to a fixed KaTeX whenever you like; 0.16 keeps working.

  ```bash
  npm i katex@^0.19.1
  ```

  zen-ui calls only `renderToString(tex, { displayMode, throwOnError: false })`,
  which is the same across these versions. A malformed equation still shows
  as KaTeX's inline error, not a thrown exception.

## Improved

- **"Homepage" on npm opens the demo site**,
  <https://algorisys-technologies.github.io/zen-ui/>, and the README starts with
  a link to the React demo — every component, with code examples. The
  repository link is still there, under "Repository".
