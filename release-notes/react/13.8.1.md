# zen-ui-react 13.8.1

*2026-11-26*

**On npm, and a labelled Slider is announced by its label.** Install with
`npm i @algorisys/zen-ui-react`.

Nothing breaks. No prop, default or visual output changed.

## New

- **Install from npm.**

  ```bash
  npm i @algorisys/zen-ui-react react react-dom
  ```

  The tarball URL and the `npm-package-react` git branch keep working (same
  build), so you do not have to switch.

zen-ui is in **beta / internal testing**: pin an exact version.

## Fixed

- **A Slider's `aria-label` / `aria-labelledby` now name the slider.** They
  named its container, not the thumb a screen reader lands on, so the slider
  was announced without a name. Each thumb carries it now — both thumbs of a
  range slider:

  ```tsx
  <Slider aria-label="Price range" defaultValue={[20, 80]} />
  ```

  Checkbox, Switch and RadioGroupItem were already correct.

## Versions are per binding now

Each zen-ui binding carries its own version from here on. Solid is the binding
in production and ships first; React, vanilla and Web Components follow. All
four started from 13.8.0, so the numbers stay comparable — a binding a few
releases behind Solid's is simply waiting for its port. Check the version you
installed before reaching for something in another binding's notes.
