# zen-ui-solid 13.8.2

*2026-11-26*

**KaTeX 0.18.2 and later can be installed beside zen-ui.** The RichText
editor's maths rendering declared `katex` as `^0.16.0`, which kept apps on the
0.16 line. KaTeX before 0.18.2 has a prototype-pollution flaw that can bypass
its `trust` restrictions (GitHub advisory, low severity), and the fix is only
in 0.18.2 onwards.

Nothing breaks. No prop, default or visual output changed.

## Fixed

- **The `katex` peer range is now `>=0.16.0 <0.20.0`.** Move to a fixed KaTeX
  whenever you like; 0.16 keeps working.

  ```bash
  npm i katex@^0.19.1
  ```

  zen-ui calls only `renderToString(tex, { displayMode, throwOnError: false })`,
  which is the same across these versions. A malformed equation still shows
  as KaTeX's inline error, not a thrown exception.
