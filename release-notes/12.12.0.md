# 12.12.0

*2026-11-16*

**Frozen rows, pivot totals and styling hooks, in every binding.** 12.11.0
shipped these in Solid. This release brings the same options, with the same
names, to **React, vanilla and web components**, along with the
right-to-left and pinning fixes that came with them. Nothing breaks: every
option is off until you set it.

If you use Solid, nothing changes for you in this release; everything below
is what 12.11.0 gave you. See [12.11.0](12.11.0.md) for the full story of
each option.

## New in React, vanilla and web components

- **Freeze rows in a DataTable.** `enableRowPinning` with `rowPinning` /
  `initialRowPinning` (`{ top: [rowId], bottom: [rowId] }`) keeps rows in
  view while the rest scroll, even when a filter or the page would hide them.
  `stickyFooter` keeps a footer without totals in view too. In web
  components: `enable-row-pinning`, `initial-row-pinning='{"top":["L1"]}'`,
  `sticky-footer`, and a `zen-row-pinning-change` event.
- **Style a column, or one cell.** A column's `meta.className` (a string, or
  a function of the row) and `meta.headerClassName`, in DataTable and
  TreeTable. The body text size is a token, `--zen-table-cell-font-size`
  (and `--zen-table-cell-line-height`).
- **Pivot grand totals.** `totals={{ row, column, grand }}` draws a totals
  column pinned to the end edge and a totals row pinned to the bottom. You
  answer for them as you answer for cells. `height` sizes the grid without a
  sized parent; `className` / `class` and `style` reach its root.
- **Schedules.** Gantt and ProductionSchedule take `rowHeight`,
  `maxBodyHeight`, `rowClassName` and `barClassName`. PlanningCalendar
  takes `laneHeight`, SpreadsheetGrid takes `cellClassName`, and Tree takes
  `itemClassName`. Their small print reads `--zen-schedule-label-font-size`.
  In web components the sizes are attributes (`row-height`,
  `max-body-height`, `lane-height`) and the class callbacks are properties.

## Fixed in React and vanilla (and web components)

- **Right-to-left pages: pinned columns stuck to the wrong edge.** A column
  pinned "left" now sticks on the start edge, which is the right edge in RTL,
  and its divider shadow faces the scrolling columns.
- **Right-to-left pivots stopped drawing after the first screen**, and their
  frozen row labels sat on the left. Both now follow the reading direction.
- **React: a pinned column's total scrolled away from it**, and **the
  checkbox column scrolled away from a pinned name.** Both now stay pinned.
  Vanilla already did both.
- **React: you could not pin a column with the keyboard.** The Columns menu
  now gives each column a submenu (Show column; Not pinned, Pin to left, Pin
  to right) that works entirely from the keyboard, as vanilla's did.
