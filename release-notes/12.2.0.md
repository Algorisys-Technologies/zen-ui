# 12.2.0

*2026-11-04*

The release that makes zen-ui fit for desktop ERP screens: ledgers, document
lists, data entry by keyboard, and apps that need to be in Hindi or Arabic as
well as English. Nothing that worked in 12.1.1 renders differently. Every
addition is opt-in, and a page that sets none of it looks and behaves exactly as
before. We checked that by recording what a screen reader gets on all 120 Solid
demo pages before and after each sweeping change, and comparing the two.

## Which binding has what

**Most of this release is in the Solid binding only for now.** zen-ui builds a
feature in Solid first, then ports it to React, vanilla and web components. The
port is the next release. Until it lands, if you use React, vanilla or web
components, the new components and props below are not in your package yet.
Each section says which bindings it covers.

These are in **every binding** today:

- **Compact density.** Set `data-density="compact"` on `<html>` (or any element)
  and everything inside it tightens: inputs, selects and md buttons go from 40px
  to 32px, and table rows, menus, filter bars, cards and object-page sections
  lose padding. Text stays the same size. Comfortable is the default and is
  exactly the old sizing. The sizes are tokens (`--zen-control-height`,
  `--zen-table-cell-padding-y`, …) if you want something in between.
- **A table that fills its pane.** `DataTable fillHeight` makes the table fill
  its parent's height. The rows scroll inside it under a header that stays put,
  and the pager stays visible below. Give the parent a height (a flex child with
  `min-height: 0`).
- **A profile menu that holds settings.** `ShellBar profile.menu` replaces
  `menuItems` with a menu body of your own: radio groups and labels as well as
  actions.

## Every built-in word can be translated (Solid)

Wrap the app in a `LocaleProvider` and pass `messages` with any of zen-ui's
strings, in any language. Anything you leave out stays English:

```tsx
<LocaleProvider locale="hi-IN" messages={{ "common.close": "बंद करें", "dataTable.noResults": "कोई परिणाम नहीं" }}>
  <App />
</LocaleProvider>
```

That covers every label, tooltip, placeholder and screen-reader announcement in
every Solid component, including words zen-ui builds for you: a date range's
"Last 7 days", a filter's summary sentence, a barcode's "the check digit should
be 4". Plurals follow each language's own rules (Hindi counts 0 as singular;
Arabic has six forms), written ICU-style:
`"{count, plural, one {# result} other {# results}}"`. The full list of keys is
`DEFAULT_MESSAGES` in `@algorisys/zen-ui-core/messages`. A label you pass to a
component directly, such as a Combobox's `placeholder`, still wins.

The same provider sets the **locale and currency** numbers are formatted in.

## Numbers the way clerks type and read them (Solid)

- **AmountField and QuantityField.** Raw digits while you type, formatted when
  you leave: 1,25,000.00 in India, 1.250,00 in Germany, each currency at its own
  decimals (INR 2, JPY 0, KWD 3). They read `1,25,000`, `2.5L`, `1.2Cr` and
  `15k`. Text that isn't a number is kept and marked invalid rather than
  silently changed, and Esc undoes the typing.
- **ObjectNumber formats a number for you:** pass `number` and `currency`
  instead of a preformatted string.

## Big lists (Solid DataTable)

- **Totals.** Put `meta: { aggregate: "sum" }` on a column (or `count`, `avg`,
  `min`, `max`, or your own function) and the table fills a footer row that
  stays in view while the rows scroll. It shows each group's subtotal when
  grouped, and follows the filters across every page. Sums are exact in decimal:
  a plain floating-point sum was wrong 332 times in 400 on generated money
  columns.
- **Export from the server.** A ledger of a million lines is not in the browser,
  so it can't be exported from there. With `onExport`, the Export menu (Excel,
  PDF, CSV, or just the selected rows) hands your code an `ExportRequest`. It's a
  few KB of JSON saying exactly what the user is looking at: columns, filters,
  sort, grouping, locale, selection. Your server builds the file. Return a
  `Blob`, a `{ url }` or nothing; a failure shows its reason by the button.
  [docs/server-export.md](../docs/server-export.md) has the contract and a
  Frappe sketch.
- **Work cell by cell, as in a spreadsheet** (`enableCellNavigation`). Arrow
  keys between cells, Enter or typing to edit, Shift-arrows and drag for ranges,
  and copy and paste with Excel and Sheets.
- **Tens of thousands of rows** (`enableRowVirtualization`). Only the visible
  rows are rendered, and grouping, selection, keyboard rows, editing, pinning
  and drag-to-reorder all keep working. 10,000 rows scroll at about 60 fps.
- **Keyboard rows** (`enableKeyboardNavigation`). One tab stop. The arrow keys
  move a row at a time, Enter opens it (`onRowActivate`), and Space selects.
- **A right-click menu for rows** (`contextMenu`), which also opens with the menu
  key or Shift+F10.

## New components (Solid)

- **FilterBuilder:** nested AND/OR conditions on any field, for advanced
  filters and report criteria, with a sentence saying what the filter does.
  The value is one plain object you can store.
- **ViewManager:** saved views beside the page title ("My overdue invoices"),
  with save, save as, a default view, a shareable link, and a Modified mark
  when the screen drifts from the view. You decide where the views are stored.
- **LookupField:** pick a row from a table of choices (a customer, an item)
  seeing several columns at once, with search across all of them. Pass
  `onSearch` to search on the server instead.
- **DateInput:** type a date the way clerks do, such as `150326`, `t` for
  today or `+7`, in the locale's day/month order. A date that doesn't exist
  is kept and flagged, never rolled into the next month.
- **TreeSelect:** pick one node from a hierarchy (a chart of accounts), with
  search that shows every match under its parents.
- **QRCode and Barcode:** drawn as SVG for screens and print, including the
  e-invoice's signed QR. Code 128, EAN-13 and Code 39 are supported. A value
  that can't be encoded says why in place of the code.
- **Shortcuts:** `useShortcut("Mod+S", save)` registers a key once (Ctrl, or
  ⌘ on a Mac). `ShortcutHelp` is the `?` overlay listing every key the screen
  answers. `Kbd` draws a key.
- **ContextMenu, DocumentTabs** (an editor's open documents as tabs), **Tile
  and TileGrid** (a launchpad).

## Smaller additions (Solid)

- **Calendar arrow keys:** ← → a day, ↑ ↓ a week, PageUp/PageDown a month. These
  keys did nothing before. `DatePicker initialFocus="selected"` opens on the
  chosen day.
- **Sidebar** can hide entirely (`collapseMode="hidden"`) or open over the
  content on narrow screens (`overlay`), and shows counts (`SidebarMenuBadge`).
- **ObjectStatus `stamp`** (DRAFT, CANCELLED as a ruled stamp). **StatCard
  `size="lg"` with a chart.** **SegmentedButtonItem `count`.** **ShellBar
  `search`** for your own control. **MicroBarChart `baseline="zero"`.**
- Combobox and Select take `invalid`, `id` and `aria-label`, so `<label for>`
  works on them.
- **Readable warning text:** the warning colour on white is 1.77:1, too faint to
  read. Set `--zen-color-warning-text` and warning text uses it instead:

  ```css
  :root { --zen-color-warning-text: var(--zen-color-warning-soft-fg); } /* 5.23:1 */
  ```

  We didn't change the default, because that would change how your pages look.

## Fixed

- **ObjectPage: tabbing to a field could leave it hidden under the sticky
  section bar** (every binding). It now lands below the bar.
- **FlexibleColumnLayout left an empty quarter of the screen** when a layout
  named a column you didn't fill (every binding). The columns you do fill now
  share the row. Layouts with every column filled are unchanged.
- **Without the opt-in `/preflight` stylesheet, some Solid components showed
  browser defaults:** Breadcrumb showed list numbers ("Home1. ›"), and StatCard
  links and sidebar link buttons were underlined in link blue. They style
  themselves now.
- **Solid DataTable:** Esc in a text editor saved the edit instead of
  discarding it. Focus was lost whenever the data changed. The number editor
  opened without focus, and the select editor opened closed. A lone sorted
  column showed a stray "1". Expanding a group row opened a detail panel.
- **Esc did nothing in a dialog while a tab inside it had focus** (Solid
  ValueHelp, ViewSettingsDialog, any Dialog containing Tabs).
- **Solid Select never told a screen reader it was invalid.** It does now.
- **TreeSelect's list was cut off** inside a card that clips its content. It
  now opens in its own layer, upward when there is more room above.
