# zen-ui-vanilla 13.8.2

*2026-11-27*

**On npm.** Install with `npm i @algorisys/zen-ui-vanilla` — no tarball URL, no
registry setup. This release also brings vanilla level with Solid 13.8.3 and
React 13.8.2: KaTeX 0.18.2 and later are accepted, and the npm page links to
the live demo.

Nothing breaks. No prop, default or visual output changed.

zen-ui is in **beta / internal testing**: pin an exact version.

## New

- **Install from npm.**

  ```bash
  npm i @algorisys/zen-ui-vanilla --save-exact
  ```

  The package is the same build as the `dist-pkg/zen-ui-vanilla.tgz` tarball,
  which keeps working if you already install from it.

## Fixed

- **The `katex` peer range is now `>=0.16.0 <0.20.0`.** The RichText editor's
  maths rendering declared `^0.16.0`, which kept apps on the 0.16 line. KaTeX
  before 0.18.2 has a prototype-pollution flaw that can bypass its `trust`
  restrictions (GitHub advisory, low severity), and the fix is only in 0.18.2
  onwards. Move to a fixed KaTeX whenever you like; 0.16 keeps working.

  ```bash
  npm i katex@^0.19.1
  ```
