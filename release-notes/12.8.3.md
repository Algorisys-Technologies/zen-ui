# 12.8.3

*2026-11-09*

**zen-ui's Solid components now work in a server-rendered SolidStart app.**
Until this release, a page that rendered any zen-ui Solid component on the
server failed in the browser as soon as it loaded, with:

```
Failed attempt to create new DOM elements during hydration.
Check that the libraries you are using support hydration.
```

The server sent the right HTML; the browser build of zen-ui could not pick it
up and tried to build its own copy instead. There was no workaround short of
turning server rendering off.

Nothing to change in your code: upgrade and the error goes away. Client-only
Solid apps behave exactly as before. React, vanilla and web components are
unaffected.

## Fixed

- **Solid: server-rendered pages hydrate.** Any SolidStart (or other Solid SSR)
  app using zen-ui now hydrates the server's HTML instead of throwing on load.
- **Solid: edge and worker runtimes get the matching build.** On Cloudflare
  Workers and other worker runtimes, Solid itself loads its server build, and
  zen-ui now does the same, so the two always agree on whether they are
  running on a server or in a browser.
