# 13.5.1

*2026-11-25*

**Solid dropdown lists no longer open with a large empty gap.** In the Solid
binding, the lists of `Select`, `Combobox` and `MultiCombobox` were pushed
about 40px in from the left edge of their panel, with about 16px of empty
space above the first option and below the last. The lists are now flush with
the panel, as they are in React.

Only the Solid binding is affected. You do not need to change any code.

## Fixed

- **Solid Select, Combobox and MultiCombobox lists had extra space.** The list
  inside each dropdown is a `<ul>`. zen-ui does not reset browser styles unless
  you import `/preflight`, so the list kept the browser's default list padding
  and margin. Those three components now remove that padding and margin
  themselves, with or without `/preflight`.

  The space of about 32px to the left of each option's text is still there on
  purpose. That is where the checkmark shows next to the selected option, the
  same as in React.
