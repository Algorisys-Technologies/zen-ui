# 12.4.0

*2026-11-05*

**Charts for business screens: AnalyticChart, in every binding.** Revenue
against margin, a profit-and-loss waterfall, a sales funnel, stock by
warehouse and month: the charts an ERP dashboard is made of, each one
clickable, each one readable as a table, and each one following your theme,
locale and currency.

Nothing is removed or renamed, and no existing component looks different.
The older `Chart` and the micro charts are unchanged.

## AnalyticChart

Twelve kinds built in: bar, line, area, combo (bars and a line on a second
axis), pie, donut, waterfall, funnel, gauge, heatmap, scatter and treemap. One
shape of props for all of them: your rows in `data`, the category field in
`x`, the value fields in `series`.

```tsx
<AnalyticChart
  type="combo"
  title="Revenue and margin by month"
  data={months}
  x="month"
  series={[
    { key: "revenue", label: "Revenue" },
    { key: "margin", label: "Margin", kind: "line", axis: "secondary" },
  ]}
  format="currency"
  secondaryFormat="percent"
  onSelect={(s) => setMonth(s.row.month)}
/>
```

- **Click a bar to drill down or filter.** `onSelect` gets the row you
  clicked, the series and the value. Drill-down is your own state: pick a
  year, hand the chart that year's quarters. Marks only look clickable when
  something is listening.
- **Every chart is also a table.** A Chart / Table switch sits above each
  chart, and the table is how a keyboard or screen-reader user reaches the
  same data and the same selection: each row's first cell is a button that
  selects exactly what a click on its mark would. Download the table as CSV
  (it opens in Excel with ₹ and € intact) or the chart as PNG.
- **Numbers read the way your users read them.** `format` is `number`,
  `currency`, `percent`, `compact` or your own function, in the locale and
  currency of the prop or of your `LocaleProvider`: ₹16,10,000.00 in en-IN,
  16.100,00 € in de-DE.
- **It follows your theme and direction.** Colours come from the theme and
  change with it; in right-to-left the category axis mirrors.
- **Add your own chart types.** A kind is one `registerChartKind` call: it
  names the ECharts parts it needs and builds the chart from your props. The
  toolbar, table, CSV, theming and selection come with it. The demos add a
  radar chart this way.

### Install ECharts to draw

AnalyticChart draws with [ECharts](https://echarts.apache.org), an
**optional** dependency, loaded only when the first chart appears. An app that
never charts downloads none of it.

```bash
npm install echarts
```

Without it, a chart shows its data as the table, with a one-line note saying
why, instead of failing.

**Web components:** `<zen-analytic-chart>`. Set `data` and `series` as
properties (or as JSON attributes in plain HTML), listen for `zen-select`.
`title` is a property only: as an attribute it would be the browser's own
tooltip.

## Chart colours

Charts get their own eight colours, `--zen-chart-1` to `--zen-chart-8`, with
lighter steps for the dark theme. Neighbouring colours stay distinguishable
for colour-blind readers, and none of them is the error red, so an ordinary
category no longer reads as bad news. Override any of them like any other
token. A waterfall's rises and falls keep the success and error colours;
change those with `--zen-chart-positive` and `--zen-chart-negative`.

## Fixes

- **Web components: setting a callback property back to `undefined` did not
  remove what it switched on.** After `header.onBack = undefined` the back
  button stayed; after `chart.onSelect = undefined` the bars still looked
  clickable. Clearing a callback now clears it.
- **ObjectPageLayout: an absolutely positioned element inside a section could
  escape the scroll area** (every binding). A visually hidden native control
  in the last section, for example, sat outside the page and could stretch
  it. It now scrolls with its section and is clipped like everything else.
